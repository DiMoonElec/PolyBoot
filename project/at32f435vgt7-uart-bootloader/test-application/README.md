# Тестовое приложение PC13 для AT32F435VGT7

Открыть `at32f435vgt7-blink.eww` в IAR EWARM и собрать Debug.

PC13 переключается раз в 1000 прерываний SysTick с периодом 1 мс:
1 секунда высокого уровня, 1 секунда низкого, полный период 2 секунды.
Основной цикл проверяет миллисекундный счётчик без блокирующих задержек.
Кварц — 16 МГц, ядро — 200 МГц; стек — 4 Кбайт, heap — 0.

Таблица векторов размещена по адресу `0x08003000`, после 12 Кбайт загрузчика.
До включения SysTick приложение устанавливает VTOR на свою `__vector_table`.
CMSIS, SPL, тактирование и SysTick используются из порта и демо без копирования.

## Память и файл обновления

- Область приложения: `0x08003000–0x080FF7FF`, 1010 Кбайт.
- Хэш исходного бинарника: `0x080FF7E0–0x080FF7EF`, 16 байт.
- MAC Poly1305: `0x080FF7F0–0x080FF7FF`, 16 байт.
- Последние 32 байта исключены из размещения кода линкером.
- Настройки: `0x080FF800–0x080FFFFF`, исключены из обновления.

Сначала собрать приложение, затем запустить `scripts/generate.bat`.
`PolyBootGen.exe` должен быть доступен через PATH. Пути батника привязаны
к его расположению, поэтому рабочая папка запуска может быть любой.

Параметры `scripts/config.xml` соответствуют демо-загрузчику:
FlashStartAddress — `0x08003000`, FlashSize — `1034240`,
DeviceID — `at32f435vgt7-uart-bootloader`. Ключи соответствуют
`../config/private_keys.inc`; при их изменении надо обновить XML.

Бинарник: `Debug/Exe/at32f435vgt7-blink.bin`.
Файл обновления: `scripts/at32f435vgt7-blink.xbin`.
Обычный bin без MAC загрузчик не запустит.

## Проверка на плате

1. Прошить демо-загрузчик программатором.
2. Через UART8/USB-UART на 115200, 8N1 активировать загрузчик и загрузить
   `scripts/at32f435vgt7-blink.xbin` утилитой обновления.
3. После запуска приложения измерить PC13: высокий и низкий уровни
   по 1 секунде, полный период 2 секунды.
4. Сбросить МК без активации загрузчика: после проверки образа и ожидания
   10 секунд приложение должно запуститься и продолжить мигание.
5. Проверить сохранность последнего сектора настроек.

Мигание после перехода из загрузчика проверяет работу VTOR, SysTick
и основного цикла приложения. При запуске отладчиком нужен Reset_Handler
приложения и MSP из его таблицы векторов.

Для нового ядра генератор должен создавать хвост [хэш:16][MAC:16].
Старые файлы обновления без этого хвоста нужно пересоздать.
