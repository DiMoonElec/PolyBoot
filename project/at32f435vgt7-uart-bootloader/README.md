# Демо PolyBoot для AT32F435VGT7

Открыть `at32f435vgt7-uart-bootloader.eww` в IAR EWARM.

## Параметры

- AT32F435VGT7, внутренняя Flash 1024 Кбайт.
- Кварц 16 МГц, ядро 200 МГц, APB1/APB2 — 100 МГц.
- UART8: PC2 — TX, PC3 — RX, GPIO MUX 8; 115200, 8N1.
- Приём и передача по IRQ, RX/TX FIFO по 128 байт, без DMA и flow control.
- SysTick — 1 мс; UART8 IRQ — приоритет 0, SysTick — приоритет 15.
- IAR: High Size, стек 4 Кбайт, heap 0.

Тактирование использует HEXT и PLL с NS = 50, MS = 1, FR = 4.
LDO устанавливается в 1,2 В, делитель Flash — 2.

## Поведение

После проверки образа загрузчик 10 секунд ожидает команду активации UART.
При активации продолжает обслуживать команды. Без неё запускает исправное
приложение. При отсутствующем или повреждённом образе остаётся в загрузчике.
Проверка целостности включена и в конфигурации Debug.

`BOOTLOADER_DISABLE_APP_RUN_CMD` оставлен выключенным: команда запуска
приложения выполняет переход. Кольцевые буферы инициализируются до UART
и разрешения его IRQ. Завершение передачи проверяется по FIFO и флагу TDC.

## Память

| Область | Адреса |
| --- | --- |
| Загрузчик, 12 Кбайт | `0x08000000–0x08002FFF` |
| Приложение, 1010 Кбайт | `0x08003000–0x080FF7FF` |
| MAC Poly1305, последние 16 байт приложения | `0x080FF7F0–0x080FF7FF` |
| Постоянные настройки, 2 Кбайт | `0x080FF800–0x080FFFFF` |

Сектор настроек исключён из обновления. Линкер приложения должен исключать
MAC и настройки из размещения его кода. Приложение устанавливает свой VTOR
до включения прерываний.

Для генератора обновления: FlashStartAddress = `0x08003000`,
FlashSize = `1034240`, DeviceID = `at32f435vgt7-uart-bootloader`.
Ключи в `config/private_keys.inc` взяты из существующего демо PolyBoot;
конфигурация генератора должна содержать те же ключи.

## Инициализация и переход

`project/hw_conf/` содержит init/deinit GPIO, UART, SysTick и тактирования.
При выходе отключаются IRQ UART8, очищаются pending и приоритеты, сбрасываются
UART8 и GPIOC, выключается их тактирование. Ядро переводится на HICK,
восстанавливаются настройки Flash/PWC и выключается LICK.
Порт перехода загружает MSP и вызывает Reset_Handler приложения.

## Проверка на плате

1. Прошить загрузчик программатором. Выходной файл:
   `Debug/Exe/at32f435vgt7-uart-bootloader.bin`.
2. Подключиться через UART8/USB-UART на 115200, 8N1, активировать загрузчик
   и проверить ответы утилите обновления.
3. Загрузить образ с указанными адресом, размером области, DeviceID и ключами.
4. Проверить запись в обоих банках, в том числе около `0x08080000`,
   и сохранность сектора настроек.
5. Проверить запуск приложения по команде и без активации спустя 10 секунд
   после начальной проверки образа, работу его прерываний и UART8.

При стирании и записи Flash прерывания временно запрещены. Время проверки
образа зависит от размера всей области приложения, а не только полезного
бинарника. Эти паузы необходимо учитывать в утилите обновления.

## Тестовое приложение

В [`test-application/`](test-application/) находится проект
`at32f435vgt7-blink.eww`: PC13 переключается каждую секунду по SysTick.
Приложение размещено с `0x08003000` и устанавливает собственный VTOR.

После его сборки `test-application/scripts/generate.bat` создаёт файл
`at32f435vgt7-blink.xbin` с параметрами и ключами демо-загрузчика.
Подробности сборки и проверки приведены в README тестового приложения.
