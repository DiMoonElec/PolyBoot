# Демо PolyBoot для AT32F413CBT7

Открыть at32f413cbt7-uart-bootloader.eww в IAR EWARM.
USART1 настроен по коду AT32 Workbench: PA9 TX / PA10 RX, 115200, 8N1,
без flow control и DMA. GPIO настраиваются вместе с UART в hw_uart_config().
Включены IRQ приёма RDBF и USART1_IRQn с приоритетом 0. Прерывание передачи
TDBE включает драйвер при заполнении TX FIFO. На железе пока не проверено.

Тактирование: кварц 16 МГц, HEXT / 2 × 25 = 200 МГц, APB1/APB2 — 100 МГц.
SysTick формирует миллисекундный счётчик времени.
Буферы UART инициализируются до включения периферии и её IRQ.

Ядро PolyBoot ожидает команду активации 10 секунд после проверки образа.
При правильной команде остаётся в загрузчике, без неё запускает исправное
приложение. Если приложение отсутствует или повреждено, остаётся в загрузчике.
BOOTLOADER_DBG_MODE не определён: проверка целостности включена и в Debug.

Размещение: загрузчик 0x08000000–0x08002FFF (12 Кбайт),
приложение 0x08003000–0x0801FFFF (116 Кбайт, включая хвост [хэш:16][MAC:16] в конце).
Сборка: оптимизация High по размеру. Адреса генератора обновления, линкера
приложения и его VTOR должны соответствовать этой карте.
Стек — 4 Кбайт, heap — 0. private_keys.inc скопирован из демо GD32;
это демонстрационные ключи, согласуемые с генератором файла обновления.

hw_deinit() отключает IRQ, SysTick, сбрасывает USART1, GPIOA и IOMUX,
убирает pending IRQ и выключает их тактирование. Затем
wk_system_clock_deinit() переключает ядро на HICK, сбрасывает CRM и
выключает LICK, включённый загрузчиком. Переход в приложение — из main:
port_application_run() только устанавливает MSP и передаёт управление
Reset_Handler. VTOR настраивает само приложение до включения прерываний.
Если в init добавляется периферия, её сброс, IRQ и тактирование надо
добавить в соответствующий deinit.

На железе проверить период SysTick 1 мс, активацию
в течение 10 секунд, прошивку через USB-UART и запуск приложения с его ISR.
Во время операций Flash прерывания временно запрещены портом: проверить
обмен с реальной утилитой прошивки на потери байтов.

В test-application/ находится отдельный проект at32f413cbt7-blink.eww:
мигание PC13 с периодом 2 секунды по SysTick. Для подготовки файла
обновления запустить test-application/scripts/generate.bat после сборки
приложения. Результат — scripts/at32f413cbt7-blink.xbin.
Обычный bin без MAC загрузчик не запустит.
