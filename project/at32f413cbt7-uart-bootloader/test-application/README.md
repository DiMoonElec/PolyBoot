# Тестовое приложение PC13

Открыть at32f413cbt7-blink.eww в IAR EWARM. Тактирование — кварц 16 МГц,
ядро 200 МГц. PC13 переключается раз в 1000 прерываний SysTick (1 мс):
1 секунда высокого уровня, 1 секунда низкого, период 2 секунды.
Основной цикл проверяет счётчик без блокирующих задержек.

Таблица векторов и приложение размещены с 0x08003000, сразу после
12 Кбайт загрузчика. В начале main VTOR устанавливается на __vector_table
этого приложения до разрешения SysTick. CMSIS, SPL, настройка тактирования
и SysTick используются из существующего порта и демо без копирования.

Линкер исключает 0x0801FFF0–0x0801FFFF: эти 16 байт предназначены для
MAC Poly1305. Файл обновления создаётся scripts/generate.bat. Для генератора:
адрес приложения 0x08003000, размер области 118784 байта (116 Кбайт,
включая MAC), DeviceID — at32f413cbt7-uart-bootloader.

Для обновления использовать scripts/at32f413cbt7-blink.xbin.
Обычный bin без MAC загрузчик не запустит. При проверке приложения отладчиком
нужно запускать его Reset_Handler с MSP из его таблицы векторов.

На плате измерить PC13: высокий и низкий уровни по 1 секунде, период
2 секунды. После запуска через загрузчик убедиться, что мигание продолжается:
это проверяет таблицу векторов, SysTick и работу основного цикла приложения.

## Создание файла обновления

Сначала собрать Debug в IAR, затем запустить scripts/generate.bat.
PolyBootGen.exe должен быть доступен через PATH. Пути в bat привязаны
к его каталогу, поэтому запускать можно из любой рабочей папки.
config.xml содержит ключи из ../config/private_keys.inc загрузчика,
адрес 0x08003000, размер 118784 байта и DeviceID демо.
При изменении ключей загрузчика надо обновить и scripts/config.xml.
