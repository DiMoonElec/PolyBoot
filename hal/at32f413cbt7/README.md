# HAL для AT32F413CBT7

Порт PolyBoot для микроконтроллера Artery AT32F413CBT7 и компилятора
IAR EWARM. Поддерживает внутреннюю Flash объёмом 128 Кбайт с сектором
стирания 1 Кбайт.

## Состав

- `CMSIS/inc/` — заголовки микроконтроллера и системного тактирования.
- `CMSIS/src/` — `SystemInit()` и стартовый код для IAR.
- `CMSIS/linker/` — стандартное описание памяти микроконтроллера для IAR.
- `SPL/` — библиотека периферии Artery, версия 2.1.6, с лицензией производителя.
- `port/inc/` — конфигурация аппаратного слоя PolyBoot.
- `port/src/` — работа с Flash и переход в приложение.

Стандартный файл линкера описывает всю память МК. Проект загрузчика должен
использовать собственные границы Flash с учётом области приложения.

## API порта

Объявления функций находятся в [`bootloader_port.h`](../../core/inc/bootloader_port.h).

| Функция | Назначение и результат |
| --- | --- |
| `port_sector_isclear(address)` | Проверяет весь сектор на `0xFF`: 1 — пуст, 0 — содержит данные. Адрес должен быть выровнен по границе сектора. |
| `port_sector_erase(address)` | Стирает сектор внутри области приложения: 0 — операция SPL завершена успешно, 1 — ошибка или недопустимый адрес. |
| `port_write_chunk(chunk, address, len)` | Записывает блок и сравнивает записанные байты с исходными: 0 — успех, 1 — ошибка. |
| `port_application_run()` | Загружает MSP и передаёт управление Reset_Handler из таблицы векторов приложения. |

Ядро PolyBoot проверяет содержимое сектора до и после стирания через
`port_sector_isclear()`. Внутри `port_sector_erase()` эта проверка не повторяется.

Запись выполняется словами по выровненным адресам, остальные байты —
побайтово. Буфер данных и адрес начала блока могут быть невыровненными.
Стирание и запись ограничены областью приложения. На время каждой операции
Flash маскируемые прерывания запрещаются; затем восстанавливается исходный
PRIMASK. Используются штатные операции и таймауты SPL.

## Подключение к проекту

В настройках препроцессора определить `AT32F413CBT7`. В пути заголовков
добавить `CMSIS/inc/`, `SPL/inc/`, `port/inc/`, `core/inc/` PolyBoot,
каталоги конфигурации проекта и заголовки Cortex-M4 из CMSIS среды IAR.

Проект предоставляет:

- `at32f413_conf.h` — включаемые модули SPL и частоты источников тактирования.
  Значение `HEXT_VALUE` также можно задать в настройках препроцессора.
- `bootloader_project_config.h` — настройки PolyBoot, включая
  `BOOTLOADER_APP_BEGIN` и `BOOTLOADER_APP_LENGTH`.
- `systick.h` с `SYSTICK_GET_VALUE()` — миллисекундный счётчик для ядра PolyBoot.
- Реализации `port_serial_putc()`, `port_serial_getc()`,
  `port_serial_transfer_completed()`, `port_boot_jumper_is_active()`
  и `port_deinit_all()`.

Начало и размер области приложения должны быть кратны 1 Кбайт.
Область должна целиком находиться во внутренней Flash за загрузчиком.
Линкеры, настройки PolyBoot и генератора обновлений должны использовать
согласованные адреса и размеры. В конце области приложения необходимо
зарезервировать 16 байт для MAC Poly1305.

## Переход в приложение

Ядро вызывает `port_deinit_all()`, затем `port_application_run()`.
Деинициализация должна остановить SysTick, отключить задействованную
периферию, её прерывания и очистить соответствующие pending-флаги.

Переход выполняется из основного цикла, в привилегированном режиме с MSP
и PRIMASK = 0. Функция перехода не изменяет NVIC, SysTick, PRIMASK и VTOR.
Приложение само устанавливает VTOR в `SystemInit()` или в начале `main()`
до включения своих прерываний.

Пример интеграции: [`at32f413cbt7-uart-bootloader`](../../project/at32f413cbt7-uart-bootloader/).
