# HAL для AT32F435VGT7

Порт PolyBoot для Artery AT32F435VGT7 и компилятора IAR EWARM.
Внутренняя Flash — 1024 Кбайт, сектор стирания — 2 Кбайт.

## Состав

- `CMSIS/inc/` — заголовки МК, системного тактирования и шаблон конфигурации.
- `CMSIS/src/` — `SystemInit()` и стартовый код IAR.
- `CMSIS/linker/` — стандартное описание памяти для IAR.
- `SPL/` — библиотека периферии Artery 2.2.2 с лицензией производителя.
- `port/inc/` — конфигурация аппаратного слоя PolyBoot.
- `port/src/` — работа с Flash и переход в приложение.

CMSIS и SPL включены без изменений. Общие заголовки Cortex-M4 предоставляет
среда IAR. Стандартный ICF описывает всю память МК; проект загрузчика
использует собственный ICF с границами его области Flash.

## API

Объявления: [`bootloader_port.h`](../../core/inc/bootloader_port.h).

| Функция | Назначение и результат |
| --- | --- |
| `port_sector_isclear(address)` | Проверка сектора на `0xFF`: 1 — пуст, 0 — содержит данные. Адрес выровнен по границе сектора. |
| `port_sector_erase(address)` | Стирание сектора внутри области приложения: 0 — успех SPL, 1 — ошибка или недопустимый адрес. |
| `port_write_chunk(chunk, address, len)` | Запись и проверка данных: 0 — успех, 1 — ошибка. |
| `port_application_run()` | Загрузка MSP и переход в Reset_Handler приложения. |

Flash состоит из двух банков:

- Bank1: `0x08000000–0x0807FFFF`.
- Bank2: `0x08080000–0x080FFFFF`.

Стирание и запись выполняются штатными функциями SPL. Флаги ошибок и
завершения выбираются отдельно для банка, которому принадлежит текущий
адрес операции. Поддерживается запись блока через границу банков.

Запись выполняется словами по выровненным адресам; невыровненное начало
и хвост — побайтово. После записи проверяются все записанные байты.
Ядро PolyBoot отдельно проверяет сектор до и после стирания.
На время каждой операции Flash прерывания запрещаются, затем
восстанавливается исходный PRIMASK. Дополнительных ожиданий и таймаутов нет.

## Подключение

Определить `AT32F435VGT7` в препроцессоре. Добавить пути `CMSIS/inc/`,
`SPL/inc/`, `port/inc/`, `core/inc/` PolyBoot, заголовки проекта и CMSIS
Cortex-M4 из IAR.

Проект предоставляет:

- `at32f435_437_conf.h` — модули SPL и частоты источников тактирования.
- `bootloader_project_config.h` — параметры PolyBoot, включая
  `BOOTLOADER_APP_BEGIN` и `BOOTLOADER_APP_LENGTH`.
- `systick.h` с миллисекундным счётчиком `SYSTICK_GET_VALUE()`.
- UART API, `port_boot_jumper_is_active()` и `port_deinit_all()`.

Начало и размер области приложения должны быть кратны 2 Кбайт и целиком
лежать во внутренней Flash за загрузчиком. Области постоянных настроек
не должны входить в обновляемую область. В конце области приложения
резервируются 16 байт под MAC Poly1305. Параметры загрузчика, генератора
обновления и линкера приложения должны быть согласованы.

## Запуск приложения

Ядро вызывает `port_deinit_all()`, затем `port_application_run()`.
Деинициализация останавливает SysTick, отключает использованную периферию,
её IRQ и очищает pending-флаги. Переход выполняется из основного цикла,
в привилегированном режиме с MSP и PRIMASK = 0.

Функция перехода только загружает MSP и вызывает Reset_Handler.
VTOR устанавливает само приложение до разрешения своих прерываний.

Демо: [`at32f435vgt7-uart-bootloader`](../../project/at32f435vgt7-uart-bootloader/).
