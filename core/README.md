# Ядро Bootloader-а

Здесь содержится platform- и board-независимый код Bootloader-а. Ядро общается с внешним миром через реализации API-функций, объявленных в файле ```bootloader_port.h```.

## Настройка команды запуска приложения

Настройки ядра задаются в `bootloader_project_config.h` конкретного проекта.
Чтобы игнорировать команду запуска приложения, определить:

```c
#define BOOTLOADER_DISABLE_APP_RUN_CMD
```

После активации загрузчика команда `CMD_APP_RUN` (`0x76`) возвращает ОК,
но загрузчик продолжает принимать команды. Проверки завершения записи и
целостности образа для этой команды не выполняются; периферия не
деинициализируется и управление приложению не передаётся.

Опция действует только на команду запуска. Автоматический запуск исправного
приложения без активации загрузчика, в том числе по `BOOTLOADER_TIMEOUT_MS`,
сохраняется. Если define отсутствует, команда работает в обычном режиме.

## Команды протокола V2

Команды доступны после ACTIVATE либо активации через существующий
`port_boot_jumper_is_active()`. Запрос каждой команды состоит ровно из
одного байта. До активации и при неверной длине запрос игнорируется,
как и другие некорректные запросы ядра. Настройки активации не меняются.

### GET_FIRMWARE_VERSION — 0x79

Перед каждым ответом ядро рассчитывает Poly1305 MAC всей области приложения
без последних 16 байт и сравнивает его с MAC в конце области. Проверка
выполняется и при `BOOTLOADER_DBG_MODE`.

При несовпадении возвращается `79 01`. При совпадении ответ содержит
8 байт: `79 00 MAJOR_L MAJOR_H MINOR_L MINOR_H PATCH_L PATCH_H`.
Результат проверки также обновляет внутренний флаг целостности прошивки.

Версия занимает 6 байт непосредственно перед MAC:
`BOOTLOADER_APP_BEGIN + BOOTLOADER_APP_LENGTH - 16 - 6`.
Генератор должен записать три uint16 LE перед расчётом MAC; linker-файл
приложения должен исключать эти 6 байт и 16 байт MAC из размещения кода.
Ядро не определяет наличие метаданных отдельно: для корректного ответа
образ с правильным MAC уже должен содержать версию по этому адресу.

Расчёт MAC синхронный: при запросе версии обработка команд приостанавливается
на время чтения всей области приложения. Это нужно учитывать в таймауте ПК.

### GET_DEVICE_ID — 0x7A

Ответ содержит 34 байта: `7A 00` и 32 байта идентификатора устройства.
Используется `BOOTLOADER_DEVICE_ID_STRING`, тот же идентификатор, который
проверяется в идентификационном блоке команды BEGIN. Свободные байты
заполнены нулями. Строка должна быть ASCII и занимать не более 32 байт
без завершающего нуля; превышение длины вызывает ошибку сборки.
При длине ровно 32 байта завершающий ноль в ответ не входит.

Команда не требует наличия прошивки и не выполняет проверку MAC.
