# Ядро Bootloader-а

Здесь содержится platform- и board-независимый код Bootloader-а. Ядро общается с внешним миром через реализации API-функций, объявленных в файле ```bootloader_port.h```.

## Настройка команды запуска приложения

Настройки ядра задаются в `bootloader_project_config.h` конкретного проекта.
Чтобы игнорировать команду запуска приложения, определить:

```c
#define BOOTLOADER_DISABLE_APP_RUN_CMD
```

После активации загрузчика команда `CMD_APP_RUN` (`0x76`) возвращает ОК,
но загрузчик продолжает принимать команды. Проверки завершения записи и
целостности образа для этой команды не выполняются; периферия не
деинициализируется и управление приложению не передаётся.

Опция действует только на команду запуска. Автоматический запуск исправного
приложения без активации загрузчика, в том числе по `BOOTLOADER_TIMEOUT_MS`,
сохраняется. Если define отсутствует, команда работает в обычном режиме.
